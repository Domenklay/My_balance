## «Мой баланс» v0.7.0 — быстрый дневник питания (20 ноября 2026)

Первый этап функционального сближения с FatSecret (собственная реализация, без копирования интерфейса и закрытых данных).

- На экране «День» показываются недавно добавленные продукты. В раскрытой форме поиска есть часто используемые продукты, определяемые по истории дневника.
- Быстрый выбор продукта открывает ввод граммовки, приёма пищи и расчёт калорий; доступны варианты 50/100/150/200 г.
- Поиск локальных продуктов учитывает название и, если присутствует, бренд.
- Любой непустой приём пищи за выбранный день можно сохранить как постоянный именованный шаблон, позже добавлять его целиком в другой день или удалять.
- Шаблон сохраняет снимки КБЖУ каждого продукта: удаление или изменение исходного продукта не меняет значения уже сохранённого шаблона и записей дневника.
- Новое поле `meal_templates` в `user://my_balance.json` автоматически добавляется при импорте прежних резервных копий. Структура и размеры шаблонов проверяются; добавление и удаление откатываются при ошибке сохранения.
- В `godot/tests/recipe_profile_test.gd` добавлены проверки шаблонов, повторного использования, независимости исторических записей, последних/частых продуктов и миграции предыдущих версий.
- Android `versionName=0.7.0`, `versionCode=17`, прежний package ID.

**Статус:** исходники опубликованы; завершение CI / готовый Android APK и испытания на телефоне пока не подтверждены. В GitHub Actions настроена сборка после изменения файлов `godot/**`. Перед обновлением обязательно экспортировать JSON-резервную копию; приложение не удалять.

**Рецепты:**

Из профиля доступны рецепты, история веса и все настройки. Регистрация и отправка личных данных в интернет не требуются.

**Надёжность и совместимость:** рецепты и профиль хранятся в прежнем локальном `user://my_balance.json`; экспорт JSON включает их. При импорте старых резервных копий отсутствующие поля автоматически и безопасно заполняются. Ошибки записи откатывают создание/редактирование/удаление рецептов, добавление порций и правки профиля. Валидируется структура и размер записей.

**Проверки:** GitHub Actions сборка прошла; все тесты прокрутки, тем, каталога, хранения данных и основной UI успешны. Новая `recipe_profile_test.gd` проверяет расчёт для печени с луком и сметаной с изменением готового веса, создание, изменение и удаление рецепта без изменения истории дневника, личный профиль, импорт старого JSON, откат ошибок сохранения и полный UI-сценарий (ручной ингредиент → сохранение → добавление порции). На реальном Godot сделаны контрольные снимки 420×900: список рецептов, редактор, профиль, редактирование и тёмные варианты. APK ZIP-проверен, содержит ARM64 Godot и scanner, SHA-256 совпал с CI.

- Быстрые переходы к записи еды, ходьбы и веса
- Недельная статистика по выбранной дате: средние калории за дни с записями, количество дней, минуты ходьбы и число силовых тренировок
- Столбики калорий за семь дней и график последних 30 взвешиваний
- Новые показатели обновляются после добавления, редактирования и удаления записей

**Ограничения:** неделя с неполными записями не отражает полного рациона; графики — информационные, не диагностические. Android APK ещё не собирается. Интерфейс и логика пока не прошли полноценное тестирование в мобильном браузере.

## Android (v0.4.0)

Добавлена Android-оболочка (`app/`) поверх офлайн-дневника. Нативная версия работает в WebView на локальном `https://appassets.androidplatform.net/assets/index.html` через AndroidX WebViewAssetLoader, поэтому сетевой доступ для дневника не требуется.

В Android-версии для экспорта JSON используется системный выбор места сохранения (Storage Access Framework); импорт работает через системный выбор файла. Данные остаются локальными на устройстве, а перенос из браузера требует **вручную экспортировать JSON из браузерной версии и импортировать его в APK**: браузер и приложение не разделяют localStorage.

### Сборка APK

Репозиторий содержит Gradle-проект: Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17, Android SDK 35. В GitHub Actions есть workflow **Android APK**, который должен создавать артефакт `my-balance-debug-apk` с `app-debug.apk`.

Можно собрать локально (после установки JDK 17, Android SDK 35 и Gradle 8.9):

```sh
gradle :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

**Статус проверки:** GitHub Actions завершился с ошибкой до запуска шагов (в задании нет выполненных шагов). Это не подтверждает ни успешную, ни неуспешную компиляцию кода: APK и тест на реальном устройстве пока не получены. Debug APK предназначен для личного тестирования, а не публикации в Google Play.

## Диагностика GitHub Actions (19.11.2026)

Последняя проверка: [run #44412381162](https://github.com/Domenklay/My_balance/actions/runs/44412381162) завершилась со статусом **failure за ~3 секунды**, при этом job имеет **пустой список шагов и runner не назначен**. Это означает, что выполнение Gradle вообще не началось. Причину невозможности запуска runner следует проверить в интерфейсе GitHub (например, сообщения в run и настройки Actions / лимиты биллинга для приватного репозитория). По одним API-данным определить конкретное ограничение нельзя.

Workflow теперь синхронизирует актуальный корневой `index.html` в Android assets непосредственно перед сборкой. Он также запускается при изменении веб-дневника. APK пока не произведён и не испытан на телефоне.

Для конфиденциальности отключено автоматическое системное резервное копирование Android: личные записи сохраняются в локальном хранилище приложения; для сохранения и переноса используйте экспорт JSON через меню приложения. Удаление приложения может удалить локальные записи.

## Нативная Godot-версия (0.5.0)

В каталоге [`godot/`](godot/) находится самостоятельное приложение **Godot 4.6.3**, не использующее WebView. В исходниках: дневник еды по дням с граммовками и БЖУ, встроенные и пользовательские продукты, календарь, записи прогулок и домашних тренировок, история веса, график, недельная статистика, заметки о вечернем голоде, локальное JSON-хранилище. В настройках предусмотрены экспорт и импорт JSON через буфер обмена.

**Важно:** Godot APK будет иметь идентификатор `com.domenklay.mybalance.godot`, отличный от прежнего Android WebView приложения. Данные автоматически между приложениями не синхронизируются; перенос требует ручного JSON-импорта. При копировании JSON в системный буфер обмена он может стать доступен другим приложениям.

### Сборка Godot Android APK через GitHub

Workflow: [Godot Android APK](.github/workflows/godot-android.yml).

Пайплайн скачивает Godot 4.6.3 и соответствующие export templates, настраивает Android SDK 35 и debug keystore, валидирует проект через headless editor и экспортирует `godot/build/MyBalance-debug.apk`. Артефакт успешного запуска называется `MyBalance-Godot-Android-APK`.

**Текущий статус:** [run #44471851233](https://github.com/Domenklay/My_balance/actions/runs/44471851233) завершился `failure` **до назначения GitHub runner, с 0 выполненных шагов**. Поэтому фактическая сборка, корректность GDScript в Godot и установка на телефон ещё не проверены, готового APK нет. Требуется устранить ограничение запуска GitHub-hosted runners в настройках Actions/биллинга этого приватного репозитория либо выделить self-hosted runner и изменить `runs-on` для него.

Для локальной сборки при установленном Godot 4.6.3, Android SDK и экспортных шаблонах:

```bash
godot --headless --editor --path godot --quit
mkdir -p godot/build
godot --headless --path godot --export-debug "Android" godot/build/MyBalance-debug.apk
```

Проверяйте apk на тестовом устройстве прежде чем доверять хранению важных записей.
