# Мой баланс 🌿

Личный дневник питания и активности для одного пользователя. Установленные по умолчанию ориентиры: 1800 ккал, начальный вес 88 кг, цель 65 кг. Их можно менять в настройках.

## Каждый день
- Выбрать дату и записать завтрак, обед, перекусы и ужин с граммовками
- Посмотреть общие калории, белки, жиры и углеводы
- Записать прогулку: длительность и при желании километры
- Записать тренировку с гантелями: минуты, упражнения, подходы и рабочий вес в заметке
- Отметить самочувствие и вечерний голод
- Внести текущий вес и посмотреть историю

## Продукты
Встроен небольшой справочник для удобного ввода; можно создавать свои продукты по этикеткам. Рассчитанные значения приблизительные.

## Как открыть
Откройте `index.html` в браузере телефона или компьютера. Это веб-версия, **не APK**.

Данные хранятся только в localStorage конкретного браузера. Синхронизации с другим устройством нет. Резервную копию можно скачать/восстановить через «Настройки».

Данные из первой версии сохраняются при обычном обновлении страницы в том же браузере, если локальное хранилище не очищалось. При переносе на другое устройство используйте экспорт и импорт JSON.

Расход калорий при физической нагрузке намеренно не вычитается автоматически из нормы питания: оценка может быть неточной.

## Обновления личного дневника
- Календарь с отметками дней, в которые есть записи еды, веса или активности
- Исправление порции записанного продукта и длительности активности кнопкой ✎
- Автоматическое сохранение текста заметок при вводе
- Фиксация пищевой ценности для новых записей на момент добавления
- Быстрое повторение последней записи еды из предыдущего дня

Старые записи сохраняются в прежнем формате. Полноценное редактирование всех полей, графики и Android APK пока не реализованы.

## Главный экран и статистика (v0.3)
- Крупный индикатор съеденных калорий относительно личной нормы
- Быстрые переходы к записи еды, ходьбы и веса
- Недельная статистика по выбранной дате: средние калории за дни с записями, количество дней, минуты ходьбы и число силовых тренировок
- Столбики калорий за семь дней и график последних 30 взвешиваний
- Новые показатели обновляются после добавления, редактирования и удаления записей

**Ограничения:** неделя с неполными записями не отражает полного рациона; графики — информационные, не диагностические. Android APK ещё не собирается. Интерфейс и логика пока не прошли полноценное тестирование в мобильном браузере.
