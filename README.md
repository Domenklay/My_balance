# Мой баланс 🌿

Русскоязычный дневник питания с подсчётом калорий и БЖУ.

## Возможности
- Учёт еды по дням и приёмам пищи
- Автоматический расчёт калорий, белков, жиров и углеводов
- Базовый каталог продуктов (включая шоколад, печенье и выпечку)
- Собственные продукты с данными по этикетке
- История веса, стартовая и целевая масса
- Настраиваемая цель калорий (по умолчанию 1800 ккал)
- Локальное хранение записей и экспорт/импорт JSON

## Запуск
Откройте `index.html` в браузере на компьютере или телефоне. Сервер и установка зависимостей не требуются.

## Важно
Это **первая веб-версия**, не Android APK. Данные сохраняются в localStorage браузера и **не синхронизируются между устройствами**. Чтобы избежать потери, регулярно делайте резервную копию на вкладке «Настройки».

Пищевая ценность встроенных продуктов приблизительная: используйте информацию с упаковки для точного учёта.

## Дальнейшее развитие
Android-приложение, рецепты, поиск и сканирование штрихкодов, графики прогресса, учёт тренировок, удобный вечерний бюджет калорий и синхронизация резервных копий.
