# Развёртывание тестового сервера MyBalance в Railway

1. Подключить GitHub-репозиторий Domenklay/My_balance к отдельному сервису Railway. В настройках Root Directory указать /community_server. Config File Path — /community_server/railway.toml.
2. Подключить постоянный Volume с путём /data. Оставить один экземпляр сервиса. Переменная MYBALANCE_DB уже задана в Dockerfile.
3. Проверить тариф и лимит расходов до запуска. Создание сервиса и диска может повлечь расходы. Не размещать реальные данные до проверки резервных копий и модерации.
4. Развернуть сервис, затем создать HTTPS-домен в Public Networking. Проверить GET /v1/health: ожидается {"version":1}. Проверить создание тестовой учётной записи, публикацию, модерацию, оценку и удаление тестовых данных.
5. Для APK 0.7.65 указать полученный HTTPS-адрес в «Рецепты → Книга рецептов сообщества». После подтверждения домена разработчик может прописать его в godot/project.godot: секция [mybalance], community_url="https://фактический-домен". Новый APK тогда получит адрес автоматически.

Контейнер запускает Gunicorn и проверяет наличие постоянного диска в Railway. Публикации проходят предварительную модерацию. Для управления очередью использовать защищённый shell сервиса и команды python server.py queue / approve ID / reject ID / hide ID. Не открывать административный доступ в интернете.

Это инфраструктура закрытого тестирования, не готовый публичный запуск. Перед Google Play необходимы условия публикации, политика конфиденциальности, обработка жалоб, блокировка пользователей, устойчивое восстановление аккаунта, резервирование и защита от злоупотреблений. Серверный URL и аккаунт хостинга не предоставлены; этот документ не означает, что сервер уже запущен.
